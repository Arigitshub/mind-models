# Roadmap

## v0.1 — Foundation ✅
- Core schema defined
- Initial cognitive models
- CODEX + spec established

## v0.2 — Behavioral + Social ✅
- Behavioral and social categories
- Category navigation and cross-links

## v0.3 — Full Category Coverage ✅
- Emotional, decision, and developmental categories
- 40 total models across all 6 categories
- Cross-reference graph through related-model links

## v1.0 — Machine-Readable Library ✅
- GitHub Pages site
- Search index
- `models.json`
- `model-chunks.json` + `.jsonl`
- CSV exports
- CI validation and generated-artifact checks

## v1.1 — Agent Reliability 🚧
- ✅ Stable, non-empty unique model IDs in every generated artifact
- ✅ Root agent integration contract (`AGENTS.md`)
- ✅ Documentation aligned with the enforced schema
- Add a formal JSON Schema for exported records
- Add evidence-quality metadata without pretending all models have equal empirical strength
- Add regression tests for identity, references, and generated exports

## v1.2 — Community
- Community-submitted models
- CLI/package validator
- Contributor evidence checklist
- Verified release artifacts
- i18n starting with the highest-demand language

## v2.0 — Ecosystem
- Visual model explorer / relationship graph
- Versioned API or package distribution
- Agent adapters for common RAG/tooling stacks
- Model tension/conflict mapping
- Optional downstream integrations without coupling the core standard to one product
